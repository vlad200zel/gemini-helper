# Инструкция по работе со Smart Helper

Коротко и по делу: как запустить, как пользоваться, что делать при ошибках.

## 1. Установка

**Нужно:** Windows 10/11, Python 3.10+, доступ к GigaChat API (ключ Сбера или Cloud.ru).

```bash
pip install -r requirements.txt
```

Пакеты: `PyQt5` (окно), `pyperclip` (буфер обмена), `requests` (запросы к API).

## 2. Ключ API — обязательный шаг

Без ключа приложение **не запустится** и сообщит об этом. Задаётся всё через переменные окружения, ключи в код вписывать не нужно. Есть два способа подключиться к GigaChat.

### Способ 1 (проще): Cloud.ru Foundation Models

Нужен один API-ключ (HTTP bearer-токен).

1. Откройте консоль Cloud.ru: **Пользователи → Сервисные аккаунты → аккаунт**.
2. **Учётные данные доступа → Создать API-ключ** (сервисы: Foundation Models) → скопируйте **Key Secret**.
3. Задайте переменную окружения:

```powershell
setx CLOUDRU_API_KEY "ваш_api_ключ"
```

После `setx` откройте новый терминал — старая сессия переменную не увидит.

### Способ 2: напрямую через Сбер

Документация: <https://developers.sber.ru/portal/products/gigachat-api>

В личном кабинете разработчика Сбера получите `client_id` и `client_secret`, затем:

```powershell
setx GIGACHAT_CLIENT_ID "ваш_client_id"
setx GIGACHAT_CLIENT_SECRET "ваш_client_secret"
```

Либо, если у вас уже есть готовый «ключ авторизации» (base64 от `client_id:client_secret`):

```powershell
setx GIGACHAT_AUTH_KEY "ваш_key_авторизации"
```

**На один запуск** (любой способ):

```powershell
$env:CLOUDRU_API_KEY = "ваш_api_ключ"; python helper.py
```

> 🔒 **Не отправляйте ключи в публичный репозиторий** — они станут доступны всем. Они читаются из переменных окружения, а не из кода, поэтому отозвать их можно в любой момент без пересборки проекта.

## 3. Запуск

```bash
python helper.py
```

В левом верхнем углу появится узкое окно с подсказкой «Выдели вопрос, жми Ctrl+C, затем Ctrl+Shift+Q». Терминал должен оставаться открытым — это и есть запущенное приложение.

Чтобы не держать терминал, создайте ярлык:

1. Правой кнопкой на рабочем столе → **Создать → Ярлык**.
2. В поле «Объект»: `pythonw "C:\путь\к\helper.py"` (`pythonw` запускает без чёрного окна консоли).
3. Название — `Smart Helper`, готово.

## 4. Как пользоваться

Каждая операция — три шага, суммарно 3–5 секунд:

1. **Скопируйте вопрос** в любом приложении: выделите текст и нажмите `Ctrl+C`. Работает в браузере, Word, PDF-читалке, тестовой системе — везде, где текст можно выделить.
2. **Нажмите `Ctrl+Shift+Q`.** Окно покажет «Думаю…».
3. **Прочитайте ответ.** Он появляется в том же окне: только суть, без вступлений и объяснений.

Полезное:

- **Перетащить окно** — зажать левой кнопкой мыши и двигать.
- **Скопировать ответ** — выделить текст в окне мышью (`Ctrl+C`).
- **Скрыть окно** — нажать **`Num 3`** (повторно — показать снова). Удобно, когда помощник не должен мешать, например во время теста.
- **Закрыть приложение** — `Ctrl+C` в терминале (или закрыть терминал).
- **Повторный вопрос** — просто скопируйте новый текст и снова нажмите хоткей; перезапуск не нужен.

## 5. Что показывает окно

| Текст в окне | Значение | Что делать |
|---|---|---|
| `Думаю…` | запрос ушёл в GigaChat | подождать 3–5 секунд |
| Ответ | модель вернула результат | пользоваться |
| `Буфер обмена пуст — сначала скопируй вопрос через Ctrl+C` | в буфере нет текста | выделить вопрос и нажать `Ctrl+C` |
| `Ошибка: ...` | сеть, ключ или API | см. раздел 6 |
| `Модель вернула пустой ответ` | сработал фильтр модели или пустой запрос | переформулировать вопрос |
| `Не удалось занять Ctrl+Shift+Q (код ...): сочетание занято` | хоткей перехвачен другой программой | закрыть конфликтующую программу или поменять хоткей в коде |

## 6. Частые ошибки

**`не заданы GIGACHAT_CLIENT_ID / GIGACHAT_CLIENT_SECRET`** — не задан ни один ключ. Укажите `CLOUDRU_API_KEY` (Способ 1) либо `GIGACHAT_CLIENT_ID` + `GIGACHAT_CLIENT_SECRET` (Способ 2) и откройте новый терминал. Проверка: `echo $env:CLOUDRU_API_KEY`.

**`v GIGACHAT_CLIENT_SECRET лежит scope «GIGACHAT_...»`** — по ошибке в `GIGACHAT_CLIENT_SECRET` подставлен scope, а нужен Client Secret проекта из кабинета Сбера.

**`API 401: ключи не приняты`** — неверный `CLOUDRU_API_KEY` либо пара `client_id`/`client_secret`. Проверьте ключи в кабинете и обновите переменные окружения.

**`API 403: нет доступа к модели`** — у ключа не настроен scope `GIGACHAT_API_PERS` либо не подключена нужная модель (для Cloud.ru проверьте список доступных Foundation Models).

**`API 429: исчерпан лимит запросов`** — превышен тариф. Подождите и попробуйте позже или расширьте лимиты в кабинете.

**`ModuleNotFoundError: PyQt5`** (или `requests`, `pyperclip`) — зависимости не установились: выполните `pip install -r requirements.txt` тем же интерпретатором Python, которым запускаете скрипт.

**SSL-ошибка при обращении к Сберу** — приложение само пробует сначала с проверкой сертификата, а при ошибке цепочки повторяет запрос без проверки (у Сбера свой корневой сертификат).

**Ответ приходит дольше 10 секунд** — медленное соединение или очередь на стороне API; окно продолжает работать, повторное нажатие хоткея во время запроса игнорируется, чтобы не плодить лишние вызовы.

## 7. Настройка под себя

Все параметры — константы в начале `helper.py`:

| Параметр | Что меняет |
|---|---|
| `CLOUDRU_MODEL` | модель через Cloud.ru Foundations (`ai-sage/GigaChat3-10B-A1.8B`) |
| `GIGACHAT_MODEL` | модель через Сбер (`GigaChat`) |
| `PROMPT` | формулировку просьбы: строже, подробнее, другим языком |
| `vk_q` + модификаторы | горячую клавишу ответа |
| `VK_NUMPAD3` | клавишу скрытия окна |
| `setFixedWidth(360)` | ширину окна |
| `move(50, 50)` | стартовую позицию окна |

## 8. Приватность

Каждый запрос уходит в сеть к API GigaChat: скопированный текст покидает компьютер. Не нажимайте хоткей с паролями, персональными данными и конфиденциальными документами в буфере. Ключи храните в переменных окружения (не в файле проекта) — так их можно отозвать без переустановки.
